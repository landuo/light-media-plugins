## Corrections and retained failures

The original `c23b`/SDK95 candidate and its failures are historical. Independent source comparisons found date integer/Unicode/overflow handling, HTTP physical-frame boundaries, Response.text error class/read timing, and Cookie domain/Max-Age differences. Current code and raw-source fixtures close those finite branches. The NO_PROXY suffix hypothesis was disproved by actual installed Requests, so no false defect or unnecessary fix was introduced.

Caller cancellation cache handling is an explicitly approved typed-runtime adaptation, not a Python source oracle: only a canceled caller skips replacing DNS/TLS cache and propagates cancellation. A fresh healthy call retries; an active caller's internal timeout still becomes an ordinary cached failure. Both original red cancellation cases, both fixed cases and ordinary-timeout controls are retained.
