## Host dependency semantics (installed source matched to fixed reference)

The plugin imports the host `CategoryHelper` from `app.modules.themoviedb`; the reference helper is a weak singleton (`category.py:28`). Constructor initializes the per-type maps and calls `init` (`33–38`), then the plugin explicitly calls `init` again. Reference `init` copies bundled YAML only if user file is absent (`44–47`), parses ruamel YAML preserving order (`49–50`), catches parse error and sets `_categorys={}` (`51–53`), catches outer file failures without rethrowing (`54–55`). Per-type maps are assigned only when `_categorys` is truthy (`57–59`); malformed/empty policy may therefore retain previous active movie/TV maps in an existing helper. Nonempty nonmapping YAML can fail at `.get()` outside that catch. A missing movie/TV key in a nonempty mapping sets that per-type map to `None`. This differs from an unconditional reset or rejecting invalid text before writing.

Reference classification is host business behavior, rather than extra plugin methods: return empty when TMDB info/categories false (`156–159`); visit category names in YAML order; false/empty rules are catch-all (`161–163`); all attributes must match, false rule values are ignored (`164–167`); `release_year` uses first four chars of release_date or first_air_date (`168–172`); a missing/false metadata attribute fails that category (`175–177`). `production_countries` reads `iso_3166_1` from object list (`178–180`); other scalar/list attributes become uppercase strings (`182–185`). Rule value is expected to be a string: comma-split without trim (`191`); inclusive numeric ranges and `!` numeric ranges expand, nonnumeric hyphen ranges become just endpoints (`193–212`); comparison is case-insensitive (`214`); positive values require an intersection, `!` values forbid any intersection (`216–222`); first complete match wins (`223–225`). Empty positive set plus exclusions supports negative-only rules. Reference does not use substring/regex matching. Rules with invalid value types may raise during classification. These details need source-based host classification verification if SDK owns the helper implementation.

Reference bundled default (`config/category.yaml:14–57`): movie order 动画电影(genre16), 华语电影(language zh,cn,bo,za), 外语电影(catch-all); TV order 国漫(genre16 + countryCN,TW,HK), 日番(genre16 + JP), 纪录片(99), 儿童(10762), 综艺(10764,10767), 国产剧(CN,TW,HK), 欧美剧(US,FR,GB,DE,ES,IT,NL,PT,RU,UK), 日韩剧(JP,KP,KR,TH,IN,SG), 未分类(catch-all). Comments/dictionaries are part of editor default text. Do not silently substitute a newly authored reduced template and claim exact default fidelity.
